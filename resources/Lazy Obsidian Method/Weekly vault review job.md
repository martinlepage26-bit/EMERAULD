# Weekly vault review job

See also [[Index]].
Run once per week.

Inputs:
- Memory notes
- Dashboards
- Project notes
- Topic gaps
- Agent logs
- Recently promoted notes

Tasks:
1. Create a weekly review note.
2. Summarize the most important work, ideas, and decisions from the week.
3. Identify active projects and next actions.
4. Identify knowledge gaps.
5. Recommend focus areas for the coming week.
6. Suggest notes to archive, merge, split, or promote.
7. Update `60_Dashboards/Weekly Review.md` and `60_Dashboards/Knowledge Gaps.md`.

Output:
- Weekly review
- Gaps list
- Next-step items
- Suggested focus areas
- Cleanup recommendations
