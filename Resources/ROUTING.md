# Resources — What Goes Here

## Purpose
`Resources/` is for **reusable reference material**: concepts, frameworks, tools, annotated sources, and processed knowledge that has no deadline and no owner-responsibility.

## Route here when the note is…
- A framework or method (PARA, RECURSO, RDAIG concepts)
- A processed reading note or annotated source
- A tool reference (Cloudflare D1 patterns, Wrangler cheatsheet)
- Evergreen concept definitions (vocabulary for PHAROS, governance terms)
- Templates that don't fit `templates/` (e.g. proposal skeletons)

## Do NOT route here
| This belongs in… | …not Resources |
|------------------|----------------|
| Active project work | `projects/` |
| Ongoing responsibilities | `Areas/` |
| Unprocessed raw input | `raw/` or `Inbox/` |
| Finished project artifacts | `archive/` |

## Legacy wiki/ — migration executed 2026-07-08
The `wiki/` folder was the pre-2026-06-29 flat dump. The full PARA migration ran on 2026-07-08: 485 notes routed to `Areas/PHAROS/`, `Areas/Writing/`, `Areas/Personal/`, `Areas/Lavoie/`, `Resources/`, and `archive/wiki-2026-07-08/` (manifest: [[_vault/PARA-MIGRATION-MANIFEST-2026-07-08|PARA Migration Manifest]]). New reference notes go here in `Resources/`, not into `wiki/`.
