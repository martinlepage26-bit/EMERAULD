# Awesome Design Resources — Curated UI-UX Reference List

## Summary

A community-curated list of high-quality design resources for UI/UX work, originally from the [gztchan/awesome-design](https://github.com/gztchan/awesome-design) GitHub repository. Useful reference when working on the `martin-lepage-site` repo visual design, [[PHAROS Method — Technical Reference|PHAROS]] product surfaces, or any new design system. Complements the [[Plugin Recommendations]] note for tooling decisions.

## Context

Ingested from the awesome-design source (2026-04-16). The the `martin-lepage-site` repo redesign established a governance-first brand system (deep navy, amber, Cormorant Garamond + DM Sans); this list informs future refinement of typography choices, color tools, and icon sourcing. Relevant to any frontend work under [[PHAROS Recalibration — Unified Governance Architecture|PHAROS]] or the [[Personal and Projects MOC|personal project suite]].

## Categories

### Get Things Done
- **Stock photos** — Unsplash, Pexels, Stocksy, Gratisography, Life of Pix, Death to Stock, SplitShire, Magdeleine
- **Color** — Coolors, Paletton, Colorable, WebGradients, uiGradients, Nippon Colors, Chinese Colors, Picular, Brand Colors, ColorHunt, Color Lisa (palettes from great artworks)
- **Icons and logos** — Font Awesome, The Noun Project, Material Design Icons, Simple Icons, iconmonstr, Iconfinder, CoreUI Icons, Bytesize Icons (SVG)
- **Typography** — Google Fonts, Font Squirrel, Adobe Fonts, Typewolf, Fonts In Use, Butterick's Practical Typography, Colophon (London/LA foundry), Klim (NZ foundry), Milieu Grotesque
- **Toolkit** — Sketch, Figma, Adobe XD, Photoshop, Illustrator, Affinity Designer, Inkscape (free)
- **Prototyping** — InVision, Marvel, Framer X, Proto.io, Origami, Principle, Protopie, Axure
- **Mockup** — Facebook Design (devices + hands), Smartmockups, BrowserFrame, Device Shots, Placeit
- **User testing** — Lookback, UserTesting, Maze, HotJar, CrazyEgg, Inspectlet

### Concepts and Learning
- **Read and Digest** — Smashing Magazine, Sidebar, Codrops, Abduzeedo, Little Big Details, Designer News, A List Apart, UX Movement, Speckyboy
- **Styleguide and Branding** — Mailchimp, Google Material Design, Apple iOS HIG, Apple macOS HIG, Atlassian Design, IBM Design Language, NASA 1976 + 2011 manuals, Ant Design (enterprise UX), Audi CI Portal
- **Books** — Universal Principles of Design, Don't Make Me Think, Thinking with Type, Universal Methods of Design, Lean UX, 100 Things Every Designer Needs to Know About People
- **Awards** — Awwwards, CSS Design Awards, FWA, Red Dot Award, iF Product Design Award
- **Conferences** — SXSW, Mirror (designers + front-end devs), Brand New Conference, What Design Can Do
- **Podcasts** — 99% Invisible, Design Matters (Debbie Millman), Layout.fm, Design Details Podcast

## Key Ideas

- Typography and color are the two highest-leverage tools for distinct-but-coherent page identities
- The Typewolf and Fonts In Use archives are strong references for type pairing decisions
- Coolors + Colorable are useful for checking contrast ratios in the existing amber/navy palette
- Nippon Colors and Chinese Colors offer restrained, named palettes that align with governance-first aesthetics
- Colophon and Klim are premium independent foundries worth checking for display type upgrades
- The NASA 1976 manual is a canonical reference for authoritative minimal identity systems — relevant to the PHAROS governance surface
- Color Lisa generates palettes from great artworks — useful for institutional palettes that carry cultural weight
