# Install and use The Human Web

1. Unzip `The-Human-Web-Obsidian.zip`.
2. In Obsidian, choose **Open folder as vault** and select the unzipped folder.
3. Open `START HERE.md`, then `The Human Web.canvas`.
4. In **Settings → Appearance → CSS snippets**, enable `body-map.css` if it is not already enabled.
5. Turn on the core Canvas and Graph view plugins if Obsidian asks.

No community plugin is required. Backlinks and Graph view update automatically as notes are added. `The Human Web.canvas` connects Body, Self, Power, and Bridge layers. `Atlas.canvas` provides the more detailed biology view.

Release 1.0 is a usable knowledge-map release. It is intentionally compact: notes state connection types, evidence boundaries, safety cautions, and source paths rather than full clinical or political essays.

Release 1.1 adds an organ and tissue layer for concrete body sites such as brain, skin, heart, lungs, liver, kidneys, thyroid, bone marrow, and skeletal muscle.

Release 1.2 deepens each body-system note with functional modules, cross-system interactions, strain signatures, and discriminating questions.

Release 1.3 standardizes frontmatter, parent MOC links, layer fields, graph tags, and explicit vault backlink sections across every Markdown file.

## Safe expansion rule

Every relationship must state its type. Biological edges use terms such as “required for,” “associated with,” or “may contribute to.” Social and political edges use terms such as “funded,” “co-founded,” “contracted with,” “claimed,” “criticized,” or “inferred.” A backlink is never proof of causation, coordination, or intent.
