# Agency under strain

```mermaid
flowchart TD
    X[Strain] --> B[Body: reduced capacity]
    X --> S[Self: rigid strategy]
    X --> P[Power: narrowed options]
    B --> A[Agency]
    S --> A
    P --> A
    A --> R[Restoration]
    R --> C[Capacity, flexibility, contestability]
```

“Under strain” is a question-generating frame. It should not erase conflict, responsibility, disease, exploitation, or the need for emergency action.
