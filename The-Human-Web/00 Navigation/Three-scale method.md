# Three-scale method

## 1. Locate the observation

Is it a bodily symptom, a behaviour, a feeling, a persuasive claim, an institutional decision, or a measurable relationship? Describe it before explaining it.

## 2. Choose the scale

- **Body** for physiology, symptoms, nutrients, conditions, pathways, and safety.
- **Self** for meaning, motivation, identity, belonging, and coaching language.
- **Power** for ownership, infrastructure, finance, state relationships, military use, and governance.

## 3. Cross scales carefully

Use a [[13 Bridges/Bridges index|bridge concept]] only when it adds explanatory value. Label the edge as established, supported, interpretive, or speculative.

## 4. Run the claim audit

Ask whether the record supports the event, the relationship, the mechanism, the intent, and the conclusion. These are separate evidentiary burdens.

## 5. Ask what restoration means

- Body: function, adequacy, regulation, safety, or capacity.
- Self: flexibility, belonging, authorship, or meaningful action.
- Power: contestability, public capacity, accountability, access, or democratic control.
