# Claim status legend

| Status | Meaning |
|---|---|
| **Verified record** | A retrievable primary source, filing, direct recording, official statement, or strong corroboration supports the narrow claim. |
| **Reported relationship** | Credible reporting supports the relationship, but the vault has not located a decisive primary record. |
| **Framework claim** | The statement accurately represents a named model or author’s view. It is not thereby scientifically established. |
| **Synthesis** | The map draws a reasoned connection across several records. |
| **Normative interpretation** | A moral or political judgment that cannot be verified like an event. |
| **Rhetorical device** | Compression, insult, analogy, urgency, or emotional framing used for persuasion. |
| **Unverified allegation** | The available record does not establish the claim. |
| **Refuted or misleading** | The wording materially misstates the available record. |

## Relationship rule

“A funded B” supports a funding edge. It does not by itself support “A controls B,” “A and B share every goal,” or “A and B coordinated event C.” Each stronger claim needs its own evidence.
