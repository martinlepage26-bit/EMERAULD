# Claim-to-map workflow

1. Preserve the exact statement and date.
2. Split compound claims into event, relationship, mechanism, intent, consequence, and judgment.
3. Find the strongest retrievable source for each part.
4. Assign a status from [[00 Navigation/Claim status legend|Claim status legend]].
5. Create one node per actor, institution, concept, or claim.
6. Label every edge with the relationship type and date range.
7. Add counterevidence, alternative interpretations, and missing evidence.
8. Keep insults in a rhetoric field, not in the factual node title.
9. Set a review date for volatile claims.
