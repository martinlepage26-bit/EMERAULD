# Expansion workflow

1. Choose the matching template in `09 Templates`.
2. Create one concept per note.
3. Add aliases people might search.
4. Add reciprocal links where the relationship is meaningful.
5. Classify each major claim with [[00 Navigation/Evidence legend|Evidence legend]].
6. Prefer an authoritative clinical source, then a systematic review, then a primary study.
7. Add safety, interaction, pregnancy, kidney, liver, and medication context when relevant.
8. Add `last_reviewed` and `review_due` dates.
9. Update one Map of Content index.
10. Add major cross-system nodes to [[Atlas.canvas|Atlas Canvas]].

## Definition of done

A node is not “done” because it has many links. It is usable when the direction of each important connection is stated, uncertainty is visible, sources are retrievable, and a reader can distinguish a learning prompt from a clinical claim.
