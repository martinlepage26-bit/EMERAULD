# Thyroid network

```mermaid
flowchart TD
    H[Hypothalamus] -->|TRH| P[Pituitary]
    P -->|TSH| T[Thyroid gland]
    I[Iodine] --> T
    T -->|T4 and T3| C[Cells and tissues]
    S[Selenium-dependent enzymes] --> C
    C -->|feedback| H
    C -->|feedback| P
```
