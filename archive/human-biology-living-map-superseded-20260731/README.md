# Install and use

1. Unzip `Human-Biology-Living-Map-Obsidian.zip`.
2. In Obsidian, choose **Open folder as vault** and select the unzipped folder.
3. Open `START HERE.md`, then `Atlas.canvas`.
4. In **Settings → Appearance → CSS snippets**, enable `body-map.css` if it is not already enabled.
5. Turn on the core Canvas and Graph view plugins if Obsidian asks.

No community plugin is required. Backlinks and Graph view update automatically as notes are added. The Canvas is a curated orientation layer and should be updated when a major node is added.

## Safe expansion rule

Every new relationship must say what kind of relationship it is. Use “associated with,” “required for,” “may contribute to,” “can be affected by,” or “hypothesis to test.” Do not use a backlink as proof of causation.
