## Versioning conventions

- **File revision** (v5, v6, v11, v12, v12.2): drafting iteration count of the disclosure document itself.
- **Protocol version** (v6.0): the PHAROS architecture version named inside the disclosure body.

These are deliberately distinct. The bundle anchor file is at revision v12; the protocol version inside is v6.0. ERRATA E2 recommends a one-sentence footnote distinguishing them.
