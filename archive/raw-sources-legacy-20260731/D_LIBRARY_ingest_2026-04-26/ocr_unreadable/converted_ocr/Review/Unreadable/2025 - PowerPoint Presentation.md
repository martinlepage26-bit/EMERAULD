Hands-On-Learning: Responsible AI
Presentation Challenge

Learning Objectives
By the end of this hands-on practice, you will be able to:
• Transform Responsible AI documentation into clear, visual

presentations for non-technical audiences
• Use Python to generate presentation slides programmatically
• Apply storytelling techniques to highlight fairness, transparency, and
governance in AI design
• Reflect on how clarity and trust enhance stakeholder engagement in

Responsible AI discussions

Description
In this hands-on Visual Studio Code practice, you'll take on the role of the
Responsible AI Lead at MoveLogix, a logistics company launching a route-

optimization algorithm. Executives have requested a concise, non-technical
presentation showing how your design mitigates ethical risks—such as unfair
route assignments, data misuse, and lack of transparency—while preserving
operational efficiency. Using Python and the python-pptx library, you'll generate
a short stakeholder-ready pitch deck that communicates fairness, accountability,

and trust clearly and persuasively.

This hands-on practice focuses on the communication aspect of Responsible AI.
You'll create a structured JSON file describing your system's ethical safeguards

and generate presentation slides directly from code to ensure consistency,
accuracy, and traceability. By combining storytelling principles with automation,
you'll learn how to translate technical AI ethics work into accessible narratives
that inspire confidence among leadership and regulators alike.

Structure of the Activity

Dataset Information
Filename: presentation_data.json

Format: Structured JSON containing presentation content
Key Features: System overview and purpose, identified ethical risks and
mitigation notes, key transparency and oversight points

Tools Used:
Visual Studio Code (any recent version)

Python 3.10 or higher
Required libraries: python-pptx (for PowerPoint generation)

Setup Requirements
Technical Prerequisites: Python 3.10+ installed and accessible from
command line
Library Installation: Run pip install python-pptx before starting
System Requirements: Any operating system with Visual Studio Code support
Required Files in Working Directory: presentation_data.json,
speaker_notes.txt, reflection.md (all created during the hands-on practice)

Scenario
You are the Responsible AI Lead at MoveLogix, a logistics company preparing to
launch a route-optimization algorithm that assigns delivery routes to drivers.

Executives have requested a concise, non-technical presentation demonstrating
how your design mitigates ethical risks—including unfair route assignments that
could disadvantage certain drivers, potential data misuse, and lack of
transparency in algorithmic decisions. Your presentation must communicate
fairness, accountability, and trust to secure leadership approval before launch.

Objective
Create a structured data file for presentation
content, programmatically generate a 6–8 slide

pitch deck using Python, write speaker notes for
non-technical delivery, and reflect on effective AI
responsibility communication.

Getting Started
1

Open Visual Studio Code and create a new folder for your hands-on
practice work

2

Install the required library by running: pip install python-pptx

3

Create a new file named presentation_data.json for your slide content

4

Create a new file named speaker_notes.txt for your delivery notes

5

Create a new file named reflection.md for your written reflection

6

Verify python-pptx installation by running: python -c "from pptx import
Presentation; print('Ready!')"
