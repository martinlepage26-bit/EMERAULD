# skills/

See also [[skills_README]].
**Instruction layer.** Each file is a reusable procedure the agent follows exactly.

Format: `skill-[name].md`
Example: `skill-morning-brief.md`, `skill-synthesis.md`, `skill-weekly-review.md`

A skill file must contain:
- A clear trigger condition ("Use this skill when...")
- Step-by-step instructions
- Expected output format
