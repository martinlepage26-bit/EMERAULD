# Fisher King Hub — Project Recovery Map

## Summary
Primary navigation surface for all active [[Healing the Fisher King — Percephal Diagnostic Protocol|Fisher King project-state notes]]. Each note is a wounded project — one where the healing question has not yet been asked or fully answered. The map is organized by Percephal tier: Tier 1 are load-bearing wounds that block external action; Tier 2 are significant supporting systems; Tier 3 are downstream and secondary. Every note lives in `10_Projects/`. Back to [[Personal and Projects MOC]].

The [[Healing the Fisher King — Percephal Diagnostic Protocol|Percephal structure]] is the vault's primary organizing lens for project recovery.
