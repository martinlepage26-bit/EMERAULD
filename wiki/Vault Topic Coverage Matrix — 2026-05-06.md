# Vault Topic Coverage Matrix — 2026-05-06

## Summary

This is the topic-level exhaustive map for the vault work I’ve done so far. It does not pretend to be a byte-for-byte mirror of every note; instead it records, for each major topic family, the canonical hub, the latest coverage artifact, and the boundary between durable synthesis and raw/source-only material. It also folds in the Documents/Downloads coverage matrix as one row of the larger vault map.

## Coverage Rule

- If a topic already has a canonical hub, I treat that hub as the durable entrypoint.
- If a topic received a recent ingest or repair pass, I add a coverage note that says what was promoted, what stayed raw, and what was already covered.
- If a file or subtopic was not promoted, it stays in `raw sources/` or in an index-only note; nothing is silently deleted from the vault’s accounting.
