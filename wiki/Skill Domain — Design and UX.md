# Skill Domain — Design and UX

## Summary

The Design and UX domain covers the skills for interface design, design systems, Figma operations, frontend visual implementation, and user experience architecture. These skills are the visual and interaction layer that bridges [[Skill Domain — Development and Testing]] (code) and the end user. They support the PHAROS Suite, DocSort, and CompassAI product surfaces documented in the [[AI Infrastructure Stack]] and [[Martin Lepage — Professional Profile|Martin's consulting practice]]. Design skills here work in close coordination with frontend development skills in [[Skill Domain — Development and Testing]] and draw on external tool evaluation from [[Skill Domain — AI and LLM Tools]]. All skills in this domain are part of the [[Skill Ecosystem — Professional Capability Registry]].
Peer domain bridges: [[Skill Domain — Agent Architecture]] (agent-facing UX, operator surfaces) and [[Skill Domain — Skill Architecture]] (packaging and maintaining design-oriented skills and patterns).
