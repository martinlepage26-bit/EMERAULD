## EMERAULD as Proof of Concept

EMERAULD (this vault) is the working instance of the product. It demonstrates:

- [[LightRAG — Graph-Based RAG System]] — Graph-based retrieval over 184+ wiki notes
- [[claude-mem — Persistent Memory Compression for Claude Code]] — Session memory layer (code projects)
- `session-state.md` — Vault-native persistence layer for Trismégiste
- [[Claude Code Skill Corpus]] — The skill layer the vault supports
- [[Ask Vault — EMERAULD Vault Briefing Skill]] — Retrieval-facing skill surface that turns the vault into a bounded question-answering briefing layer
- [[Vault Deep Linking Pass — 2026-05-06]] — Current graph-maintenance proof: low-inbound notes are identified, anchored, and documented instead of left as isolated wiki files.
- [[Vault Linking Gaps & Bridge Opportunities — 2026-05-01]] and [[Vault Cluster Discovery and Linking Opportunities — 2026-05-01]] — Earlier scan and gap-roadmap artifacts showing how the vault's graph structure is audited and repaired over time.
- [[Client Logo Strategy — Monogram Pivot and SMB Branding Lessons]] — Example of how operational client lessons become reusable wiki knowledge rather than one-off project chatter.
- [[Desktop Obsidian and Personal Assistant Setup Logs — 2026-04-14]] — Setup provenance for the product logic: Windows Obsidian as app surface, WSL as runtime, Markdown folders as memory, and LightRAG as retrieval layer.

The marketplace bundle now ships both the memory-layer vault and a sanitized optional local runtime for WSL buyers: setup script, query CLI, watcher, service notes, and Windows launcher.

The vault structure (raw sources / wiki / maps / templates / assets / scripts) is the product architecture.
