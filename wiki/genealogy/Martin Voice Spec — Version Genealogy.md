# Martin Voice Spec — Version Genealogy

## Summary

Canonical index for the Martin voice-spec corpus found on `D:` and adjacent archive folders. The current official version is the mislabeled `AI Governance Constitution.pdf`, which opens as `Unified Martin Voice Spec v4.0`. Earlier files preserve the long-form operator glossary and the compressed runtime macro layer that eventually became the official rewrite table. `v3` belongs to the MOBI / Mobius stage.

## Context

This lineage sits inside the APEX archive under `COMPRESS/` and is also referenced by the HENRY writing system. Use this note as the landing page whenever the question is "which voice spec version is current?" or "which operator set should I read first?".

## Metadata Bridge

The scan did not surface a standalone `Martin Voice Spec v2` voice file. Instead, the archive metadata points to a governance-build bridge recorded in the PHAROS method repository:

- `AIGOV1 + VOICEOP1 -> AIGOV2 + VOICEOP2`
- `Voice Operator 1` marks the first formal containment layer
- `Dottie` appears as the adjacent evidentiary counter-voice and claim-audit layer

Read that bridge as a lineage marker, not as a separate end-user voice file. It explains why the corpus jumps from the v1 family to the v3 / v4.0 labeled documents while still preserving an internal `v2` governance step.
