# Reboot Performance Gender Identity — Version Genealogy

## Summary

Key arc: short working draft → elaborated manuscript with Foucault/performativity framework → submission-ready MT version → expanded MT-REV version. Multiple files are exact duplicates with hash-tagged filenames indicating email/cloud sync copies.

## Context
Links to the canonical wiki note [[Reboot — Performance, Gender, and Computing of Identity]], [[Historical Academic Portfolio — Pre-PHAROS Scholarly Work]], and [[Research and Papers MOC]]. Part of Martin's early work on animated series and digital identity.

## Diff Summaries

### v1 → v2
~170 changed lines. Title word changes from "Computing" to "Computation." Abstract substantially rewritten: v2's abstract is the same opening but shifts analytical framing. Body substantially expanded (+958 words). v2 appears to be a more fully developed manuscript pass.

### v2 → v3 (MT)
~51 changed lines. The abstract is completely replaced: v3's abstract introduces Foucault's dispositif, gamification/surveillance parallels, algorithmic addiction, and Hexadecimal as "a queer, glitch-based vision of chaos." This is the theoretically sharpest version of the abstract.

### v3 → v4 (MT-REV)
~51 changed lines. The abstract is extended with an added final paragraph: "This article argues that ReBoot not only visualizes these theories but recalibrates them: by depicting gender and subjectivity as executable processes, it exposes the limits of performativity and disciplinarity in a computational paradigm." Title formatting: quotation marks removed from "Reboot." Some punctuation normalized (em-dashes → commas). Word count increases by ~936 words.

## Canonical Version
**`Reboot Performance, Gender, and the Computing of IdentityMT-REV (1)__B65F6707.docx`** is the most complete and theoretically developed version (7,391 words). The hash-tagged filenames indicate cloud/email sync copies rather than distinct drafts.

## Key Insights from Version History
The paper has two distinct intellectual moments: an early "computing of identity" version focused on gender performance and character analysis (v1/v2), and the MT version which pivots to Foucault's dispositif and introduces Hexadecimal as a queer glitch figure. The MT-REV then extends the abstract to make a stronger claim about ReBoot "recalibrating" performativity theory for computational paradigms. The `_6FC1EE89` stub is puzzling — only 615 words, possibly an abstract-only extract or metadata record.
