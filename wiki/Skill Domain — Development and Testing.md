# Skill Domain — Development and Testing

## Summary

The Development and Testing domain contains the skills for building, testing, debugging, reviewing, and shipping software: TDD workflows, web app testing, CI/CD automation, GitHub operations, and systematic debugging. This domain is Codex's primary implementation surface in the [[Skill Ecosystem — Professional Capability Registry]] and is the execution layer for all product work across the PHAROS Suite, DocSort, and CompassAI. It connects upstream to [[Skill Domain — Design and UX]] (design-to-code handoff) and downstream to [[Skill Domain — Deployment and Infrastructure]] (build-to-deploy pipeline). Planning and architecture decisions in this domain are Claude's contribution; implementation and test execution belong to Codex.
