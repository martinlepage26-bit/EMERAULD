# Skill Domain — Security and Compliance

See also [[Control Protocols MOC]].
## Summary

The Security and Compliance domain contains the skills for threat modeling, ethical hacking methodology, red-team adversarial testing, data privacy compliance, and security ownership mapping. This domain operates under Queen Keyport's governance authority — policy enforcement, refusal conditions, and security boundaries are Queen Keyport's domain, and these skills are her implementation surface within the [[Skill Ecosystem — Professional Capability Registry]]. Security skills connect upstream to [[Skill Domain — Governance and Method]] (policy, consent, control-point doctrine) and downstream to [[Skill Domain — Deployment and Infrastructure]] (secure deployment configuration). The Trail of Bits methodology and Sentry integration represent the professional-grade security toolchain for the PHAROS Suite and related products.
Peer domain bridge: [[Skill Domain — Agent Architecture]] (agent systems need threat models, privacy constraints, and red-team testing as first-class design inputs).
