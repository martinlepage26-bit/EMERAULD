# Provisional Arbitration Charter — Argus Layer 9.5

The root Documents intake preserved two versions of a PHAROS constitutional provisional that names an unresolved apex problem in the method stack: when recursive layers conflict, what authority decides?

## Core Claim

The charter does not install a permanent supreme authority. It formalizes the unresolved arbitration problem as a governed provisional: record conflicts, apply a current hierarchy, and derive the durable rule from logged cases rather than from assertion.

## Authority Candidates

- Constitution / Layer 13: strongest normative claim, but vulnerable to brittleness if later layers legitimately outgrow it.
- Operator / Martin: de facto sovereign, but unconstrained override would make the governance stack decorative.
- Henry / adversarial gate: strong veto and immune function, but a veto alone is not a positive decision rule.
- Latest layer: most current recursive state, but recency is not legitimacy.

## Provisional Meaning

The charter is important because it applies the PHAROS standard to PHAROS itself. It identifies the legitimacy gap created when a system advises clients on governance while its own apex conflict rule remains informal. The v1.1 revision makes the bootstrapping paradox explicit: the charter is created by the same operator sovereignty it is trying to constrain.
