# GSD Tier 1 — Core Workflow Skills Hub

## Summary

Tier 1 is the highest-priority documentation cluster in the Codex skills inventory: the GSD workflow system that governs project initialization, phase discussion, planning, execution, verification, shipping, and session handoff. This page begins the vault-side bridge for that cluster and ties the workflow surfaces into the unified skill ecosystem.

## Agent Attribution

| Agent | Role |
|---|---|
| Codex | Primary workflow surface; command family dispatch, milestone management, session continuity |
| Claude | Planning, review, architectural decisions, session handoff oversight |

## Scope

This hub is for the workflow family, not for one-off task skills. It covers the reusable command families that keep long sessions structured and resumable:

- Planning and phase orchestration: `gsd-new-project`, `gsd-discuss-phase`, `gsd-plan-phase`, `gsd-execute-phase`
- Verification and quality gates: `gsd-verify-work`, `gsd-review`, `gsd-secure-phase`, `gsd-docs-update`
- Session and milestone continuity: `gsd-pause-work`, `gsd-resume-work`, `gsd-session-report`, `gsd-complete-milestone`, `gsd-new-milestone`
- Fast path and utility commands: `gsd-next`, `gsd-fast`, `gsd-quick`, `gsd-debug`, `gsd-health`, `gsd-stats`
- Workspace and workstream control: `gsd-workstreams`, `gsd-new-workspace`, `gsd-list-workspaces`, `gsd-remove-workspace`

## Why this hub exists

- The vault already had two GSD system notes, but no dedicated Tier 1 hub for the command family they describe.
- The Codex skills inventory flagged Tier 1 as the first documentation target because it is the day-to-day workflow backbone.
- This hub makes the Tier 1 cluster easy to navigate from the master skill registry instead of leaving the GSD material scattered across separate notes.
