# Skill Domain — Skill Architecture

## Summary

The Skill Architecture domain is the meta-layer of the [[Skill Ecosystem — Professional Capability Registry]]: the skills that build, audit, compose, and maintain all other skills. This is where [[Martin Lepage — Authored Skills|Martin's authored methodology]] turns on itself — the practices that produce, validate, and evolve the skill corpus. The four authored skills in this domain (Skill Development Workflow, Skill-Pairing, skill-architect, Agatha Unified Skill System) are the foundational toolchain for all skill authorship and composition across both Claude and Codex surfaces. This domain connects upstream to [[Skill Domain — Governance and Method]] (quality gates and evidence requirements) and downstream to every other domain that depends on maintained, coherent skills.

Peer domain: [[Skill Domain — Design and UX]] — where “skill as interface” becomes visible (documentation, affordances, handoff clarity) and where many skill surfaces are actually exercised by operators.
