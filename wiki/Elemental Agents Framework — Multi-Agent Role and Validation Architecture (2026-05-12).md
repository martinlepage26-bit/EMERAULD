# Elemental Agents Framework — Multi-Agent Role and Validation Architecture (2026-05-12)

## Summary

`/mnt/d/elemental-agents` is a markdown-native multi-agent execution framework emphasizing explicit routing, role ownership, and triangulated delivery verification.

Verified raw-source copy is preserved at `raw/D-drive-scan-2026-05-12/elemental-agents/`.

## Core Structure

- `agents/`: 10 role contracts (`01-prime-coordinator` -> `10-delivery-operator`).
- `orchestration/`: intake -> context -> planning bridge -> execution loop -> validation gates -> recovery.
- `validation/`: three-angle validation (build, quality, governance).
- `combinations/`: dual/triple combination matrices with manifestation rules and validation checks.

---

## Operational Doctrine Extracts

- Prime Coordinator owns end-to-end completion, explicit assignment, and escalation.
- Delivery Operator signs off only when inventory + evidence + risk ledger are present.
- Execution loop enforces short slices with immediate checks and no unresolved critical defects.
- Triangulated validation requires all three angles to pass before declaring completion.
