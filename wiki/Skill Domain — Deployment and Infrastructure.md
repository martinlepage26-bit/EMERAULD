# Skill Domain — Deployment and Infrastructure

## Summary

The Deployment and Infrastructure domain covers the skills for building backends, configuring databases, deploying to cloud and edge targets, and reducing operational costs. This domain is the production surface of the [[Skill Ecosystem — Professional Capability Registry]]: where code from [[Skill Domain — Development and Testing]] becomes running services. It includes Cloudflare Pages, Netlify, Render, and Vercel deploy skills; FastAPI and ASP.NET Core backend development; database design; and CLI automation tools. Hermes provides routing and monitoring governance; Gadget evaluates tooling options; Codex executes builds and deploys. The [[AI Infrastructure Stack]] documents the canonical stack this domain supports.

## Agent Attribution

| Agent | Role |
|---|---|
| Codex | Primary; build, deploy, CI/CD, backend implementation |
| Gadget | Tooling selection, infrastructure evaluation, platform comparison |
| Hermes | Routing, monitoring, escalation — integration governance for deployed services |
