# Obsidian Agent Vault — Demo Script (Avatar Version)

Target: 2.5–3 minutes. Paced for ElevenLabs text-to-video.
Each paragraph = one visual beat.

---

If you're using Claude Code, Cursor, or any coding agent that reads your files, you've already hit this problem. Every new session starts from zero. You re-paste your project context. You re-explain your stack. You re-describe rules you've already written down somewhere. It works, barely. Then it breaks.

The fix isn't a RAG pipeline. It's a vault that's already structured the way agents think.

This is the Obsidian Agent Vault. When you unzip it, you get four folders: raw for incoming captures, wiki for linked knowledge, skills for reusable agent instructions, and archive for finished material. Plus a set of hub-note templates and a file called CLAUDE.md.

CLAUDE.md is the real product. The agent reads it first, every session. It tells the agent who you are, what you're building, what stack you use, what rules to follow, and where to look in the vault. You edit it once. The agent never asks you to re-explain the project again.

Here's what most people's CLAUDE.md looks like: three lines. "This is my project. Tech: React, Node." That's it. The agent knows the stack, and nothing else.

Here's what it looks like after ten minutes with the vault template: projects with wiki-links, standing rules, preferences, a vault map. The agent knows what to read, where to navigate, and when to stop searching.

The difference between those two files is the difference between an agent that searches blind and an agent that navigates.

Once the vault is running, it grows. You drop raw notes in, the agent synthesizes them into linked wiki pages. Hub notes connect your projects, people, and decisions. After a few weeks, your agent has a memory layer it can actually use. No database. No embeddings. Just structure.

Template pack is forty-nine dollars. Guided setup is two-ninety-nine. Link in the description. If you're tired of re-explaining yourself every session, this is the fix.
