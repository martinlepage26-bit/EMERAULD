# Example: Post-Incident Retrospective

See also [[Control Protocols MOC]].
## Input

"Write the retrospective for last week's checkout outage."

## Route

- Prime Coordinator
- Observability Sentinel
- Quality Auditor
- Governance Steward

## Execution summary

1. Reconstruct the timeline from logs, alerts, and chat transcripts.
2. Separate proximate cause from contributing conditions.
3. Identify the validation gates that did not catch the failure.
4. Propose corrective actions with owners and deadlines.

## Expected output

- Annotated incident timeline
- Cause classification (proximate, contributing, latent)
- Gate-failure analysis
- Corrective action register with owners and dates
