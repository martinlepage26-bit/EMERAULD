- Each chapter begins on a **recto (odd) page** — insert blank verso page if needed
- Top margin of chapter opening: **increase to 1.5–2 inches** (drop-chapter style)

## 7. Body Text Special Formatting

| Element | Style |
|---|---|
| Block quotations (4+ lines) | Indent 0.5" both sides, no quotation marks, 10.5pt, 1 line above and below |
| Inline quotations | Standard quotation marks in body text |
| Italics use | Titles, foreign words, first use of key terms, emphasis |
| Bold use | Avoid in body; reserve for section headings only |
| Em dash | — no spaces on either side (Chicago style) |
| Ellipsis | … with no space before, one space after |
| Footnotes vs. endnotes | Endnotes preferred (less disruptive for a monograph; keeps pages clean) |
| Endnote format | Garamond 9.5pt, numbered, collected at back of book |
| Twelve competences table | Full-width table, centered, simple lines, 10pt |
