# Governance Index

Hub for all three-agent authority architecture, governance decisions, and operational detail.

## Summary

The three-agent stack (HEPHAISTOS, Queen Keyport, Hermes) is the binding control architecture for all work. HEPHAISTOS defines artifacts and scope. Queen Keyport governs constraints and controls. Hermes routes approved decisions and monitors execution. All three are co-equal authorities operating without hierarchy; conflicts escalate to the [[Operator]] (Martin Lepage) for arbitration.
