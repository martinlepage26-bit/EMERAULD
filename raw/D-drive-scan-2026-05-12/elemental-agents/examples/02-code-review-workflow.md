# Example: Code Review Workflow

See also [[Control Protocols MOC]].
## Input

"Review this module and list high-risk defects first."

## Route

- Context Cartographer
- Quality Auditor
- Security Guardian

## Execution summary

1. Read target files and tests.
2. Classify findings by severity.
3. Provide concrete fixes and validation steps.

## Expected output

- Severity-ordered findings
- File and line evidence
- Remediation guidance
