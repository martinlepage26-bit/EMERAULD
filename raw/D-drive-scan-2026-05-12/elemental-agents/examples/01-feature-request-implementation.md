See also [[Control Protocols MOC]].

"Create a new framework folder with specific markdown files and verify counts."

## Route

- Prime Coordinator

- Implementation Engineer
- Quality Auditor
- Test Operator

## Execution summary

1. Build folder map and required file list.
2. Create folders and markdown files.
3. Verify with filesystem command.
4. Confirm counts and inspect representative files.

- Created paths
