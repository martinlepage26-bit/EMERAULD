# Example: Release Readiness

See also [[Control Protocols MOC]].
## Input

"Confirm this delivery is production-ready."

## Route

- Quality Auditor
- Test Operator
- Governance Steward
- Delivery Operator

## Execution summary

1. Run structure/content/validation gates.
2. Resolve blockers or declare stop-ship.
3. Package evidence and decision record.

## Expected output

- Go/no-go decision
- Gate status matrix
- Handoff bundle summary
