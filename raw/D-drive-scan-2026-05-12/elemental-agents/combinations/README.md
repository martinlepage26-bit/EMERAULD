# Combinations Map

See also [[Control Protocols MOC]].
This folder contains the full dual and triple combination map for:
Water, Air, Wind, Fire, Earth, Wood, Metal, Spirit, Chi, and Akasha.

## Automation contract

Every combination includes an explicit autonomous automation behavior:

- trigger conditions,
- closed-loop execution pattern,
- and escalation pathway.

This ensures combinations self-orchestrate under workflow pressure and do not depend on manual intervention for routine correction cycles.
