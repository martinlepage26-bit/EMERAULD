# Validation Gates

See also [[03-triangulated-verification]].
## Goal

Block incomplete or unverifiable outputs from being delivered.

## Gates

1. Structure gate: required files and counts exist.
2. Content gate: sampled files contain operational detail.
3. Native validation gate: documented commands executed where available.
4. Traceability gate: assumptions and deviations are recorded.

## Exit criteria

- All mandatory gates pass.
- Any waived gate is justified with evidence.
