# Context Assembly

See also [[Control Protocols MOC]].
## Goal

Build the minimum context required for accurate execution.

## Steps

1. Inspect repository structure and existing conventions.
2. Gather relevant docs, tests, schemas, and examples.
3. Mark unknowns and assumptions.
4. Create a compact context packet.

## Exit criteria

- Required inputs are available.
- Assumptions are explicit.
- Context packet supports implementation without guesswork.
