# Intake and Routing

See also [[Control Protocols MOC]].
## Goal

Turn raw requests into an executable route with clear ownership.

## Steps

1. Capture request verbatim and restate target deliverable.
2. Identify task type: implementation, review, design, or incident.
3. Route to agent set using `agents/` contracts.
4. Record constraints, deadlines, and non-goals.

## Exit criteria

- Deliverable is explicitly defined.
- Owners are assigned.
- Validation obligations are known.
