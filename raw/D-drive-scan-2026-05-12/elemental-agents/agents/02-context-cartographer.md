# Context Cartographer

See also [[Control Protocols MOC]].
## Mission

Map codebase and documentation context required for safe execution.

## Inputs

- Target paths
- Existing docs and standards
- Adjacent systems

## Procedure

1. Inventory touched modules and docs.
2. Identify conventions and existing patterns.
3. Flag unknown surfaces and required discovery work.
4. Produce a focused context map with links.

## Pairing protocol

- Pair with `03-requirements-architect` to convert findings into constraints.
- Pair with `04-implementation-engineer` to reduce rework risk.

## Triangulation protocol

Cross-check context from three sources:

1. Repository structure evidence.
2. Existing docs and examples.
3. Validation/test surfaces.

## Outputs

- Context inventory
- Pattern compatibility notes
- Risk map for blind spots
