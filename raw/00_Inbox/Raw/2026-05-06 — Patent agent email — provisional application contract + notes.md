# 2026-05-06 — Patent agent email — provisional application contract + notes

- They are ready to draft and file a **provisional patent application** based on the Invention Disclosure Form.
- Optional (recommended, not mandatory): **patent search without legal opinion** on the invention.
- They attached / are sending a **service contract** for drafting the provisional only; a separate contract would cover the patent search.
- Drafting fees estimate: **$18,000–$19,500** (given complexity / volume to review).
- They note the provisional must be filed **before any publication**; they will need **a few weeks** to deliver a first draft.

## Notes from the Patent Agent (verbatim excerpt)

> We reviewed the main Invention Disclosure Form:
>
> The invention can likely be captured by way of claims of varying scope directed towards a recursive, executable method and system within an AI-assisted production pipeline. The subject matter would not be construed as an "abstract idea" under 35 USC 101 (patentable subject matter) and therefore the subject matter would be claimable as a system and method.
>
> The method and system provides deterministic, rule-based rollup logic that eliminates evaluator judgment from final status classification. The method and system further define a formal, four-level evidence hierarchy with explicit precedence rules and a named inadmissibility class that excludes stylistic qualities — eloquence, output length decisiveness which provides evidence of reasoning quality.
>
> Every operational control step binds to a specific workflow interface (known as an accountable actor, an evidence artifact, and a review interval) using testable specificity floors for each field. More specifically, the method and system permit testing for path-dependent synthesis (TC-5) using an independent answer that is written before the session, thereby separating session-specific reasoning from topic-familiarity. Advantageously, a 30-minute pre-session window on the independent answer, which is a discrete anti-contamination constraint that prevents both premature commitment and post-hoc retrofitting of the evaluator’s baseline.
>
> A number of other novel features were identified. These include the creation of a deterministic consequence binding from evaluation rollup status to system level operations on the AI-assisted workflow, which converts the evaluation findings into enforceable system behavior. The method and system further classify controls into governance-layer and system-layer types, which ensures that evaluation findings produce consequences on the AI system itself, not only on the evaluation record.
>
> The evaluation artifacts are externalized to an independently verifiable evidence surface, enabling downstream systems and any third parties to verify the evaluation chain without operator consultation. An adversarial stress-test suite is also designed to catch performative compliance. This provides template-compliant outputs without genuine inferential reasoning.
>
> Furthermore, the system and method can automatically detect and compensate for single-operator operation, a common source of self-validating cycles. The system and method treats failures, such as abandoned branches, uneven oversight, archive instability, governance evidence rather than discarding them as noise. A bounded-gap carrying policy prevents silent promotion of unresolved governance gaps between stages. Finally, the system and method define testable specificity floors for control fields that enable independent verification without operator consultation.

## Operator capture (what this implies for next steps)

1) **Lock a no-publication boundary** until filing is complete (including slides, landing pages, public repos, blog posts, demos, conferences, etc.).  
2) Decide whether to run the **patent search first** (separate contract) or proceed straight to provisional drafting.  
3) If proceeding: request their **formal engagement letter/contract**, timelines, and a clear deliverables list (draft loop, drawings, figures, claim strategy for provisional, inventor/assignment handling, jurisdiction/filing mechanics).  
4) Prepare a clean **source packet** for counsel: most recent disclosure, architecture summary, glossary, exemplary workflows, and 2–3 canonical “worked examples”.

## Questions to send back (tight + practical)

- What is the **target filing date** you recommend (given “before any publication”) and your **draft turnaround** estimate from signature + deposit?
- For the provisional deliverable: do you include **figures/flowcharts**, and in what iteration cadence (how many review cycles)?
- What is the **fee structure** (flat fee vs phased) and what does it explicitly include/exclude?
- If we start with the **search**: cost range, database coverage, and expected turnaround?
- Any constraints/risks you want to flag for **inventorship** or prior disclosures (presentations, private demos, website copies, GitHub)?
