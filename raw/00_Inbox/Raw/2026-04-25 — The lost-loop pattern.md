# The lost-loop pattern

**What it is.** A recurring loop I just ran three times in one hour: ask an agent to build a system → it builds → I get overwhelmed → I say "I'm lost" or "are you lying" → I ask the next agent to do the same thing in different packaging → repeat. Today's instance: HERMES Dashboard rebuild → Codex PARA scaffold → Codex seeding offer → my "read the vault and write the notes" request.

**Why it matters now.** It's costing runway. It has nothing to do with the systems themselves — Codex's PARA overlay is fine, the HERMES panel is fine, the Lazy Obsidian Method is fine. The loop fires when something else is hard, and the system-shopping is the avoidance.

**What I need to decide / know.** What is the something-else that is hard right now. (Probably: send the GD email, approve SF Phase 0, point Reflexive Inhabitation Audit at a real X.) Until I name that, the next agent setup is just a different room in the same maze.
