# wiki/

**Navigation layer.** Synthesized, interlinked notes the agent uses to answer questions.

Every note here must have:
- Frontmatter with `tags:` and `updated:`
- At least one `[[backlink]]` to a related note
- The original question or context that prompted the note

Hub notes (topic overviews) use the prefix `hub-`.
Example: `hub-projects.md`, `hub-tools.md`, `hub-health.md`
