# Kairos by vertical: sell the fix, not the loop

**Idea:** owners do not buy "a system that plans, drafts, posts and learns". They buy a fix for a problem they already say out loud. Each vertical below gets its own named offer, headline and set of presets (topics, seasonal calendar, reply rules, banned words), built on the same engine. The product stays one product; the front door changes per industry.

Legend. **Fit** = how well today's features solve it (H/M/L). **Gap** = what we would need to build. **Verify** = a regulatory point to confirm with the relevant body before selling; nothing here is legal advice.

## Where to start

**Pick three, sell them by name, and prove them with real clients before adding more.**

1. **Plumbers / HVAC and contractors (#2, #3, #4).** Strongest route in: Groupe Lavoie (plumbing, excavation, fencing, property management) is already a client relationship and covers four rows of this table on its own. A pilot there produces real before-and-after proof for the whole trades family. Needs the RBQ licence-number feature first.
2. **Auto garages (#1).** The clearest named problem with a legal deadline behind it. Easy to explain in one sentence, easy to measure (bookings in October vs last year).
3. **Clinics and professional services (#8, #10).** Where Kairos's real difference is strongest: approval first, strict banned words, nothing auto-sent. "Safe to Post" sells the safety model that competitors do not have.

Property management (#5) rides along with the Lavoie pilot (GVI).

## How this changes the product (small)

- **Presets per vertical:** topics, a seasonal calendar, reply rules and a banned-word pack, applied at setup. Setup asks "What kind of business?" first. (Fits iteration 1's guided setup in `DESIGN-ITERATION.md`.)
- **One landing page per offer** on the same template as `SALES-PAGE-SPEC.md`, headline swapped: e.g. **TIRE SEASON? SORTED.**, **NEVER FORGOTTEN.**, **SAFE TO POST.**
- **Licence / registration field** that is automatically added to every post where a regulator requires it (RBQ, OACIQ, professional orders).
- **Video per vertical:** each row's "video angle" becomes a one-sentence template for Kairos Video.

## To verify before selling each vertical

Winter tire dates; RBQ licence-number advertising rule; OACIQ advertising rules; each professional order's advertising and testimonial rules; French-language prominence rules for bilingual posts. Each needs a short check with the source body; none should appear in client copy until confirmed.
