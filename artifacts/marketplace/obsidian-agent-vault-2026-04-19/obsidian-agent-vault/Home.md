## Folders

| Folder | Purpose |
|--------|---------|
| `raw/` | Incoming captures - unprocessed notes, clippings, transcriptions |
| `wiki/` | Linked, durable knowledge - the agent's primary retrieval layer |
| `skills/` | Reusable agent instructions and workflow files: Ilyris, Ariun, and Mnara |
| `scripts/` | Optional helper scripts, including guide-name customization, runtime setup, local querying, and auto-ingest |
| `services/` | Notes for the optional local runtime services |
| `archive/` | Completed, retired, or superseded material |
| `templates/` | Hub-note templates for projects, people, concepts, decisions, MOCs |

## Getting Started

1. Read [[START_HERE]].
2. Edit [[CLAUDE.md]] with your details.
3. Create your first project hub note using the template in `templates/hub_project.md`.
4. Drop a real note into `raw/`, then ask Ilyris to synthesize it into `wiki/`.
5. Optional: install the bundled runtime with `bash scripts/setup.sh`.

That's the loop. Everything else builds from here.
