# raw/

See also [[Writing and Novels MOC]].
**Purpose:** Inbox for unprocessed material.

Drop anything here: meeting notes, voice transcriptions, article clippings, brain dumps, screenshots, chat exports, anything you haven't organized yet.

**Rules for the agent:**
- Read from raw/ only when wiki/ doesn't have what's needed.
- When synthesizing a raw note into wiki/, move or delete the original from raw/ to avoid duplication.
- Never link directly to raw/ notes from hub notes. Synthesize first.
- Treat raw material as unverified until promoted into wiki/.

**Rules for the human:**
- Don't organize here. Just capture.
- Process regularly: the goal is for raw/ to be small and wiki/ to be growing.
