# Ariun - Link Guide

## Purpose

Check whether wiki notes are connected well enough for a future human or agent to find them again.

## When to Use

- A new wiki note has just been created.
- The user asks you to check links, backlinks, maps, or retrieval paths.
- A note answers a project question but feels isolated.

## Steps

1. **Read** the target wiki note and identify its topic, project, people, concepts, and decisions.
2. **Find** the closest hub note, map of content, project note, person note, or related wiki note.
3. **Add** at least one useful `[[wikilink]]` from the target note to a hub or related note.
4. **Update** the hub or map so it links back to the target note when the relationship is durable.
5. **Check** that the note title is descriptive enough to be found later.

## Output

A brief link report naming:

- the note checked
- the links added or confirmed
- any missing hub or map that should be created next

## Rules

- Never add fake links just to satisfy a count.
- Prefer one honest link over three decorative links.
- If no good hub exists, say so and recommend the closest template in `templates/`.
- Use Obsidian `[[wikilinks]]` for internal links.
