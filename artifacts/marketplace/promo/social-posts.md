## LinkedIn Post

I've been using AI coding agents — Claude Code, Cursor, Aider — for most of my research and development work for the past year. They're genuinely useful. But there's a recurring friction point that no one talks about much: every session starts cold.

You explain the project. You re-establish the constraints. You re-state the decisions you already made last week. The agent has no memory of any of it. And if you're doing this five times a day across a complex project, the overhead adds up fast.

The standard advice is to write a better system prompt. That helps at the margins. The real problem is structural — there's no stable place for an agent to read persistent context from. Nothing it can reliably find at the start of every session that tells it: here's the project, here's what we decided, here's how we work.

So I built one. An Obsidian vault structured specifically for AI agent workflows. The agent reads a context-loader file (CLAUDE.md) automatically. The folder structure is predictable: raw captures, synthesized wiki notes, skill guides, archive, templates. Three workflow guides handle the recurring tasks — synthesis, linking, archiving — so the agent knows what to do with new material.

The local runtime is optional: a setup script for WSL, a query CLI, a file watcher. Windows launcher included. Everything is plain markdown. No SaaS layer, no API dependency, no subscription.

I built this for my own work first. After a few months of daily use it was stable enough to package for others.
