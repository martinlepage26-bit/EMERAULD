# backend/requirements.txt
# Runtime dependencies for the PHAROS FastAPI backend
#
# CRITICAL: dnspython is required for mongodb+srv:// URI resolution.
# Motor/PyMongo use DNS SRV lookups to connect to MongoDB Atlas.
# Removing this package causes silent runtime failure on all DB-backed endpoints.
# Do not remove. Do not move to test-only. It is a production runtime dependency.
