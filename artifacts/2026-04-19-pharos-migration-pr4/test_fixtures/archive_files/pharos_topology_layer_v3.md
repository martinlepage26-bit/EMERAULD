# PHAROS Topology Layer v3

See also [[Governance and PHAROS MOC]].
Formal topology of the governance method. Three named constructs:
- **topology_theseus** — recursion shell over the target rollup.
- **topology_auryn** — bounded binding. Auryn is the fixed-point anchor.
- **topology_hopf** — Hopf fibration closure. The Hopf bundle closes the recursion.

The topology layer is the architectural invariant: any governance topology built
on PHAROS inherits the theseus / auryn / hopf triple.
