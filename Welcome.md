## Vault Layout

- `wiki/` — durable, linked working notes
- `raw/` — canonical intake lane for newly scanned, verified source files
- `raw sources/` — captured source material and unsynthesized imports
- `templates/` — reusable note shapes
- `assets/` — PDFs, exports, and supporting files

## First Retrieval Loop

1. Scan broadly; verify integrity, readability, provenance, and duplicates.
2. Hard-move verified source files into `raw/`.
3. Create or update a durable note in `wiki/`.
4. Link that note back into a MOC or adjacent page.
