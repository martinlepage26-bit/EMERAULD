# Quiet Compliance Workbench — Standing Tone Rule

> For future Claude: standing product-language rule set by Martin on 2026-07-06 (relayed via rook-509) governing ALL UI/API/docs language in [[Contremaître — Groupe Lavoie Field-Operations Platform|Contremaître]] and [[LegiPro Canada-QC — Compliance Evidence Service Plan|LegiPro]]. Load this before writing any user-facing text for the Lavoie software workstream. The rule softens language only — it never weakens source rigor, evidence traceability, or the human-review workflow.

## Summary

Compliance surfaces in the [[Areas/Lavoie/AREA|Groupe Lavoie]] software stack must read as "a zen place to work, not a courtroom simulator" — calm, operational language instead of panic and disclaimer theatre. Martin set this as a standing direction on 2026-07-06; it was applied the same day across all [[LegiPro Canada-QC — Compliance Evidence Service Plan|LegiPro]] docs (lavoie-fieldops commit `bd643fe`, pushed; parent plan §16 commit `7c30917`, local).

## Context

The rule emerged from the rook-509 tone task during the [[Contremaître — Groupe Lavoie Field-Operations Platform|Contremaître]] full-package work (2026-07-05/06): the first drafts of the LegiPro plan leaned on warning banners and legal-liability vocabulary, and Martin pulled the register back. Both product notes carry the rule inline; this note gives it a stable address since it binds every future LegiPro/Contremaître language decision.

## Details

**Approved calm vocabulary (FR):** Sources trouvées · Points à confirmer · Dossier prêt pour revue · Source officielle · Ajouter une note de revue · Exporter le dossier. Review states: *En préparation* / *Prêt pour revue*.

**Avoid on everyday surfaces:** repeated warning banners, popups, and scary terms — illegal, non-compliant, no legal advice, liability. Formal caveats stay short and neutral, and belong mostly on exports, guides, and admin surfaces.

**Hard boundary — softening is UX language only.** Unchanged by this rule: source rigor, source cards, evidence traceability, rights boundaries, and the human-professional-review workflow (the human decides; LegiPro organizes and points). Design target: confidence and flow — "a quiet compliance workbench, not anxiety confetti".

**Confidence:** stated (Martin, via rook-509, 2026-07-06).
