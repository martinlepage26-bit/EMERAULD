## Summary

One day of work turned Martin's editorial corrections into mechanical build gates on the [[Areas/Lavoie/AREA|Lavoie]] plan-set dossiers: 17×11in landscape PDFs generated by self-contained Python/WeasyPrint scripts, one numbered directory per version (5146→5165), each with README manifest, SHA-256 hashes, stale-terms scan, and previews. ### Register rules (operator corrections, standing for all client-facing Lavoie documents)

- No em dashes (standing writing rule, enforced at build).
- No scaffolding or meta voice: the document never talks about itself ("Ce dossier", "cette feuille", "comment lire"). Master rule adopted from Codex: **"Montrer la chose. Ne pas décrire qu'on montre la chose."**
- Never tell the client what he already knows.
- "Argent" is vulgar in client-facing text; speak **en termes de dépôt**. Payment schedule stays out of client-facing documents entirely; canonical pointer sentence verbatim: « Prix, rythme et modalités : dans l'offre commerciale. »
- No jargon (API, backend, Alembic, OSRM...).
- Anti-AI-Slop Rule v2.0 (Codex): ban grand language (échelle, profondeur, fondation, vision...), journey terms, "simple"; sentences ≤20 words; facts over framing. Canon file: `~/Lavoie/dossiers-client/REGLE-ECRITURE-v2.md`; staged tokens not yet merged: `stale-terms-v2-staged.txt`.
- Mistral API output is diagnostic, not prose authority (its corporate flattening and curly apostrophes were rejected). Key secured at `~/.mistral-ml@infrafabric.io-api.key` (chmod 600), pointer in credentials quickref.

### Design canon (client-approved)

Grid-text baseline rhythm is sacred: body 17px × 1.34 ≈ 24px = .25in cell. Progress bar 7px `#d8cdae`, kept obvious. One-line titles. Fonts and layout adapt to content volume (13.5/15.5px index was rejected as unreadable). P-100 pattern: core rectangle white and narrower, description words colored like their satellite boxes. Canons live in `dossiers-client/DESIGN.md` and `PRODUCT.md`.

### Build-time enforcement (the governance mechanism)

Every generator embeds `_scan_stale(html)`: reads the stale-terms file, regex-scans the rendered HTML and the generator source, and raises SystemExit before writing the PDF. Negative-tested (poisoned build exits 1). Token layers per dossier: version tokens, em dash, scaffolding voice, monetary register (`\bargent\b` word-bounded after the "chargent" false positive; `\bversement` after "téléversements"), payment terms, jargon, architect-standard residue. The 62-page unified packet build (`build_unifie.py`) adds page-count and mediabox asserts, index parsed from source HTML with a +1 cover offset, and pypdf text-extraction probes.
