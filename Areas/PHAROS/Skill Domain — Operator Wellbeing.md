# Skill Domain — Operator Wellbeing

## Summary

The Operator Wellbeing domain is the smallest domain in the [[Skill Ecosystem — Professional Capability Registry]] — currently a single skill — but it occupies a structurally distinct position: it operates without an agent intermediary, reporting directly to the operator. The [[Operator-Check Skill — Burnout Cascade Interrupt]] intercepts burnout cascades and capacity overload before they contaminate the reasoning stack. This domain is a node in [[Martin Lepage — Authored Skills]] and connects to [[Skill Domain — Governance and Method]] via the [[hitl-awareness]] cross-reference (human-in-the-loop as a governance concern, not only a wellbeing one). If this domain grows, it can absorb wellbeing-adjacent skills such as pacing protocols, session boundary management, and rest-state transitions.

## Agent Attribution

| Agent | Role |
|---|---|
| Operator-direct | No agent intermediary; self-monitoring and capacity interruption |
| Trismégiste | Continuity awareness, session state tracking, operator fatigue signals across sessions |

- [[Operator-Check Skill — Burnout Cascade Interrupt]] — primary wellbeing interrupt; checks operator capacity, flags burnout cascades
- [[hitl-awareness]] — cross-reference from [[Skill Domain — Governance and Method]]; human oversight as both a governance gate and a wellbeing mechanism

## Domain Growth Note

This domain currently has one primary skill. If Martin develops additional capacity management, pacing, or rest-state protocols, they belong here. Wellbeing-adjacent skills in other domains (e.g., [[hitl-awareness]], [[verification-before-completion]]) are cross-listed rather than moved; they remain anchored in their primary domain.
