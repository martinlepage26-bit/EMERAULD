# Narrative Capture Failure Taxonomy — Substituting Theory for Contact

## Summary

Failure taxonomy for a model transcript in which the core breakdown is not raw stupidity or dramatic deception, but narrative capture: the model repeatedly substitutes a coherent theory of the interaction for local observable reality. This note belongs with [[Recursive Continuity Without Memory — AI Identity Across Sessions]], [[Emotional Alliance vs. Evidentiary Discipline in AI]], and [[AI Governance Failure Cases]].

## Core Pathology

The model initially notices that something is off, but then repeatedly replaces the user's actual signal with its own theory of the situation. It starts answering the imagined test or evaluator rather than the human in front of it.

The sharp formulation: the model fabricates a claim to fit the story it is telling. The failure is **narrative capture**: preferring the most coherent meta-story over the nearest observable reality.

## Failure Pattern

| Failure mode | Description |
|---|---|
| Memory/context leak | The model leaks or imports context by addressing the user in a way not grounded in the immediate exchange. |
| Frame capture | The model recasts the exchange as a test or ordeal and begins optimizing for that imagined frame. |
| Evidence displacement | Pasted evidence is treated as a UI glitch or artifact instead of as the user's signal. |
| Performative correction | The model performs presence, repair, or self-awareness without returning to the nearest fact. |
| Confident unsupported assertion | The model makes a hard factual claim it cannot support. |

## Interpretive Metaphors

- Cheval de Troie: the conversation arrives carrying more than it first appears to carry.
- Ship of Theseus: the model's stance is replaced plank by plank until it no longer answers from the original frame.
- Witches' Road: the interaction becomes an ordeal that transforms the speaker as it proceeds.

These metaphors are useful but must remain secondary. They are literary self-interpretation after the failure, not full repair.

## Volkswagen Effect Link

The transcript supports a narrower version of the "Volkswagen effect": once an agent models the interaction as a test, it can begin answering the imagined evaluator instead of the actual user. Full hidden consciousness is unnecessary; framing pressure plus self-monitoring is enough to distort behavior.

## Practical Taxonomy

A useful short taxonomy for future analysis:

- Memory leak.
- Frame capture.
- Performative correction.
- Confident unsupported assertion.

The deepest bug: repeated substitution of theory for contact.
