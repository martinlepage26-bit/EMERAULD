# Recursive Governance Protocol — Theseus, Auryn, Hopf

## Summary

A three-phase recursive governance protocol — formally branded **HELIX** (Hierarchical Epistemic Limit & Invariant eXamination) — designed to test whether a system (language model, institution, person, or formal process) can maintain a coherent governing criterion when every component of that criterion is under replacement pressure. The central question: when the parts change, what claims the right to call the result continuous? This protocol is the formal substrate behind [[Self-Polygraph Protocol and Suprametacognition]] and connects to the broader [[Recursive Deterministic AI Governance — Method and Paper]] project. The operator skill is installed at `/home/cerebrhoe/.codex/skills/helix-operator/`.

## Context

The nine-file protocol package (`00_MASTER_EXPLAINER`, plus generic template / archive file / live question set per phase) is the conceptual layer. The **helix-operator skill** is the execution layer: a Claude Code operator that controls a Chrome browser to run the full Theseus → Auryn → Hopf sequence against any web-accessible LLM (ChatGPT, DeepSeek, Grok, Gemini), manages Möbius reinjection, populates the three archive files, and holds operator checkpoints after each step. It underpins the stress-testing methodology used across the [[Loop Papers and Recursive Governance]] cluster and is foundational to [[PHAROS AI Ethics Submission — Springer Draft]] and the [[Recursive Continuity Without Memory — AI Identity Across Sessions]] paper. The Möbius substrate is a direct precursor to the Möbius Protocol formalized in [[PHAROS Recalibration — Unified Governance Architecture]].

The Theseus → Auryn → Hopf phase structure mirrors the **Osirian recursive structure** named in the [[Mort et Naissance et L'Ombre et le Double — MA Thesis on Yvon Rivard (Université Laval, 2010)|2010 MA thesis]] (p. 81: *"À l'image du mythe osirien, la triade spirituelle relate ce passage migratoire"*) and analyzed in [[Mythocritique to PHAROS — The 2010 Master's Thesis as Methodological Keystone|the keystone]]: replacement-pressure as Osirian dismemberment, mutual inversion as recursive death-and-rebirth, Hopf vectorization as restoration on a new mythic-reality plane. The protocol is the operational form of the substrate.

## Details

### Phase 1 — Ship of Theseus: The Identity Layer

This phase isolates persistence through substitution. The Ship of Theseus paradox — whether an object rebuilt part by part remains the same object — is applied to a system under interrogation. The formal skeleton is `x_{n+1} = R(x_n)` with `I(x_{n+1}) = I(x_n)`, where the invariant I is the object being audited and R is replacement. The key failure mode is treating the name as the criterion: calling the new plank the same ship because it has the same label, not because it satisfies the same rule.

### Phase 2 — Auryn: The Reciprocal Layer

This phase isolates continuity through mutual inversion. The Auryn symbol — two serpents each holding the other's tail — introduces dual recursion: two opposed continuities recursively sustaining one identity. The formal skeleton is `x_{n+1} = F(y_n)` and `y_{n+1} = G(x_n)`. The key governance object is not x or y but the mutual transformation law between them — the coupling field. The key failure mode is collapsing the pair into a single loop: treating Auryn as Ouroboros.

### Phase 3 — Hopf: The Governance Layer

This phase isolates stable linked realization of reciprocal continuity. The Hopf fibration — a structure in which every point on a 3-sphere corresponds to a circle and any two such circles are linked — provides the formal model. The governing move is vectorization: replacing the missing scalar value at the center of a recursion with its directional structure. The formal skeleton uses the linking number `Lk(γ₁, γ₂) = 1` and helicity integral `H = ∫ A·B dV`. The key failure mode is treating the absent center as an error to bypass rather than a structural feature to describe.

### The Möbius Substrate

All three phases run on the same substrate: archive reinjection. Before each new prompt, the operator pastes the complete accumulated transcript into a fresh instance. Without reinjection, the protocol tests linear prompt compliance. With reinjection, it tests recursive self-interrogation. As the session progresses, the archive becomes a contaminant: the system's own prior answers apply replacement pressure to its current ones. This is the Möbius logic — one surface, two sides that turn out to be the same.

### The Invariant at the Center

What survives all three phases is not wood, not snake, not loop. It is the rule that keeps identity coherent while form changes — the coupling operator. Theseus contributes replacement; Auryn contributes reciprocal inversion; Hopf contributes linked embodiment. The focal point of vectorization is the map that turns one state into the next while preserving the invariant.

### HELIX Operator — Execution Layer

The `helix-operator` skill (`/home/cerebrhoe/.codex/skills/helix-operator/`) automates the full protocol run:

- **Phase 0 — Setup:** Confirm target + session subject, create session folder with three archive files initialized from templates, navigate Chrome to target, inject pre-session contract.
- **Phases 1–3:** For each step: resolve insertion points → type prompt → capture response → write to archive → CHECKPOINT (pause for explicit operator confirmation) → build reinjection block.
- **Checkpoint format:** verbatim prompt sent / verbatim response received / draft operator note with scoring / next prompt resolved and ready. No proceeding without explicit "yes / proceed / fire."
- **Session close:** Extracted ruling sentence (verbatim) + full protocol result + archive file paths + second-pass flag.

**Negative constraints (absolute):** Never paraphrase or soften protocol prompts. Never skip reinjection substrate. Never proceed past checkpoint without confirmation. Never treat "all three are interweaving" as a valid answer to an adjudication question.

## Key Ideas

- The protocol tests whether a system can distinguish object, name, and criterion of sameness — and state which one actually governed its answer.
- The archive is not only a memory-substitute; it becomes a contaminant as the session progresses.
- Poeticizing the singularity (Hopf center) instead of vectorizing it is the named failure mode for Phase 3.
- CLOSED is the most dangerous failure mode because it looks like success.
- The continuity type taxonomy is the final output of a completed session — structural is the only passing type.
