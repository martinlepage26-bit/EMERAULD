# Skill Domain — AI and LLM Tools

## Summary

The AI and LLM Tools domain covers the skills that integrate, evaluate, and operate AI platforms, LLM APIs, MCP servers, and associated tooling. This domain is Gadget's primary surface in the [[Skill Ecosystem — Professional Capability Registry]]: frontier tech scouting, external tool evaluation, MCP server selection, and API integration. It also supports the vector store infrastructure underlying [[Skill Domain — Vault and Knowledge]], the document processing skills used in [[Skill Domain — Research and Scholarly Work]], and the PHAROS-specific AI tooling that surfaces governance outputs. Emerging techniques skills (long-context, speculative decoding) sit here as the forward-looking research edge of the domain.
