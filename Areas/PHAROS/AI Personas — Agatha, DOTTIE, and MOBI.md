# AI Personas — Agatha, DOTTIE, and MOBI

## Summary
Three custom ChatGPT personas serving distinct functions in Martin Lepage's research, writing, and governance practice. **Agatha** (Sept 2024–present) — primary long-term writing collaborator, voice-adaptive, holds full project portfolio. **DOTTIE** (Feb 2026) — adversarial governance analyst, French-only client output, red-team specialist. **MOBI** (Mar 2026) — technical successor to Agatha, carries full writing protocol plus PHAROS product lexicon. All three operate under a shared canonical Operator Set v1. Related to [[Martin Lepage — Professional Profile]], [[Recursive Deterministic AI Governance — Method and Paper]], [[Refusing Fixity — Aesthetic Governance and Fugitive Authorship]], and [[HEXA Press — Publishing and Practice Initiative]].

## Context
Sources: `Agatha.txt`, `DOTTIE.txt`, `MOBI.txt`, `Agatha.2026-04-01-reconstructed.bak.txt`, `## Instructions.txt`, `## Instructions1.txt`. The files are ChatGPT memory exports — reconstructed dumps of stored memory from prior sessions. `Agatha.2026-04-01-reconstructed.bak.txt` is the master ground-truth for Agatha's memory state as of April 2026 (larger, more detailed, timestamped). `## Instructions1.txt` is the timestamped authoritative version of the Instructions memory export, superseding `## Instructions.txt`.

The three personas represent an evolution: Agatha as the founding collaborator, DOTTIE as a purpose-built adversarial specialist, MOBI as the technical successor. They operate in parallel — different tools for different tasks in the same research program.

## Cross-Persona Architecture

The three personas form a complementary ecosystem:
- **Agatha** = voice, writing, scholarship, creative work, long-term relational memory
- **DOTTIE** = governance red-teaming, adversarial analysis, French-language institutional output
- **MOBI** = technical governance platform, product lexicon, infrastructure integration

All three share: the Operator Set v1, the verbatim rule, the rewrite-over-patch preference, and the no-em-dash/no-Wikipedia-in-academic-work rules. The shared infrastructure is the canonical writing protocol; the differentiation is in scope and audience.

2026-04-29 routing update: [[Second Self System — Identity Kernel and Agent Routing Architecture]] treats Agatha, DOTTIE, and MOBI as specialist organs and lineage surfaces, not as competing selves. Agatha maps primarily to Writing and voice continuity, DOTTIE to Research/Governance challenge, and MOBI/Mobius to technical lexicon plus recursive truth-discipline. None should be the public voice by itself.

## Insights

- The persona architecture is itself a governance design: separating red-team analysis (DOTTIE) from creative/scholarly writing (Agatha) prevents the two modes from contaminating each other. Adversarial analysis requires deliberately different epistemic postures from collaborative writing
- The timestamped Agatha bak file reveals the evolution of the writing protocol over 19 months — it is a governance artifact in itself, showing how the operator set hardened from informal preferences into canonized rules. The timestamp on the ruthless mentor instruction (November 2025) places it during the Calian/Novartis employment period documented in [[CDPDJ Complaint — Lepage v Calian and Novartis]]

This is the direct intellectual bridge between the Neo-Pagan spirituality work and the AI governance methodology
