# Skill Map — Canonical Routed Skills (2026-05-06)

This note is the vault-facing index of the **canonical routed skills** (the ones that
the system actually routes through), organized by scope.

Canonical source of truth for the definitions and drift-resolution notes:
[[../governance/hephaistos/SKILL-MAP.md|governance/hephaistos/SKILL-MAP.md]].

Separate layer: the full Codex-side corpus inventory (241 directories) lives in:
[[Codex Skills Inventory — Complete Registry (241 Skills)]].

## How Skills Organize

- **Scope first**: forging vs governance vs right-arms vs research vs output vs meta vs routing.
- **Routing beats catalog**: this list is smaller than the full 241-skill inventory because
  it represents the *skills with explicit routing doctrine*.
- **Vault documentation status**: each skill below links to a vault note.
  If a note did not exist, a stub was created under `wiki/skills/` so the graph is no longer orphaned.
