# Obsidian Agent Vault — Setup Guide

## Summary
A one-page quick-start guide for the product described in [[Obsidian Agent Vault — Launch Kit]]. It explains how to unzip the vault, open it in Obsidian, configure `CLAUDE.md`, use the four core folders correctly, and run the first raw-to-wiki retrieval loop. Part of [[Personal and Projects MOC]].

## Core Steps

1. Unzip the vault into a stable folder.
2. Open that folder as a vault in Obsidian.
3. Edit `CLAUDE.md` with the user's name, active projects, stack, preferences, and standing rules.
4. Use the folder system correctly:
   `raw/` for fresh captures, `wiki/` for durable notes, `skills/` for reusable workflows, `archive/` for completed or stale material.
5. Run one real retrieval loop:
   add a note to `raw/`, synthesize it into `wiki/`, and link it back to a hub or project note.

---

## Success Criteria

- The agent can answer a project question without the operator re-pasting context.
- The agent can move from `CLAUDE.md` into linked wiki notes rather than searching blindly.
- A raw note can be turned into a linked wiki note in one pass.
