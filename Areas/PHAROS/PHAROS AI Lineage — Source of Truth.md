# PHAROS AI Lineage — Source of Truth

## Summary

The canonical chronology and architecture note for the [[PHAROS]] project's AI layer. It documents how the system evolved from a relational writing companion (Agatha) through governed operators (Henry, Dottie, Mobius) into modular [[HEPHAISTOS|Hephaistos]]-mediated skill infrastructure deployed through Codex and Claude.

## Context

This document is the backbone for the [[AI Society Manuscript — From AI Anxiety to Recursive Governance]] and for the [[PHAROS Cross-AI Strategy Matrix]]. It governs how the project's AI lineage should be narrated across paper drafts, builder files, and repository work. It is upstream of the [[PHAROS Final Voice Operator — GPT Creator]] spec.

The lineage maps onto the [[EMERAULD Second Brain — Project Context]] as evidence of how governance design accumulated across tools rather than residing in one system.

2026-04-29 addition: [[Second Self System — Identity Kernel and Agent Routing Architecture]] turns this lineage into an explicit identity-and-routing architecture. The governing distinction is that agents should represent Martin's judgment through governed capabilities, not recreate a personality or let multiple fragments speak publicly as competing selves.

## Details

The document uses a Brain/Map split to distinguish reasoning behavior from the information environment:

**Canonical compression:**
`Agatha -> Voice Operator 1 -> Governess Agatha -> Henry -> Reviewer #2 injection -> Dottie -> Mobius / SuperPower / desktop -> governance revision into skills -> MASTERskill meta-governance -> skill-architect explicit skill design -> Hephaistos / WSL -> Codex and Claude implementation -> late specialized skills such as trace-investigator`

**Filesystem date scaffold** (from `pharos_research_timeline_since_sept2024.html`):
- Phase 0 / Epistemic ignition: Sept 2024 – Jan 2026
- AI Governance Turn: Feb–Mar 2026
- Phase 1 / Protocol closure + first containment: Feb 14 – Mar 14, 2026
- Phase 2 / Governance revision + skill distribution: Mar 14–23, 2026
- Promotion gate (manual operator override required): Mar 25, 2026

**Named agent progression:**
1. **Simple ChatGPT as Agatha** — relational companion, ChatGPT Plus, Extended Thinking (not Instant)
2. **Voice Operator 1** — first formal containment: voice discipline, admissibility, evidence handling
3. **Governess Agatha GPT** — warmth + containment; support becomes rule-bound
4. **Henry** — academic build-and-review operator; inspectable manuscript workflow
5. **Reviewer #2 injection into Henry** — adversarial pressure internalized into the workflow
6. **Dottie GPT** — evidentiary counter-voice; claim-audit; ChatGPT Business
7. **Mobius GPT + SuperPower + desktop** — self-polygraph; truth-discipline; ChatGPT Business
8. **Governance revision into standalone skills** — `skill.md` units replace prompt-only logic
9. **MASTERskill meta-governance** — governs the governed skills
10. **skill-architect** — explicit design and audit of reusable skills; Brain vs. Map separation
11. **Hephaistos / WSL / Codex / Claude** — cross-agent fabrication and deployment layer
12. **trace-investigator** — function-specific: authority travel and term drift
13. **Promotion gate** — explicit no-auto-promote stop; governance authority retained locally

**Cross-use strategy:** Different AIs were used to generate, pressure, and implement each other's prompts. Agatha (ChatGPT Plus), Dottie and Mobius (ChatGPT Business), Gemini Pro (prompt creation), Claude (forge and implementation), Codex (operational build). Disagreement was method, not noise.

2026-04-28 source bridge: [[Documents Root Loose Files Intake — 2026-04-28]] preserved loose root files that support this lineage from another surface, especially [[PHAROS Cross-AI Strategy Matrix]] trace material (`Gemini a dit.txt`) and [[Local Hardware and Discovery Snapshot — Laptop A]] for the WSL/Windows operating context.

**Evidence labels used:** Direct / Supported / Thin — distinguishing archival certainty from reconstructive inference.

**Open gaps:** Agatha's canonical raw spec is partly reconstructive; Dottie's standalone GPT packet is thinner than Henry's; exact frequency of Gemini/Dottie/Claude prompt-forging passes is not fully reconstructed.

| Phase | Brain (reasoning) | Map (environment) |
|---|---|---|

| Middle | Containment, review discipline, anti-drift logic, consent-governed support | Evidence packets, term locks, logs, registers, layered structures, contracts |
| Late | Claim audit, self-polygraph, skill design, meta-governance, cross-AI prompt forging | `skill.md`, `MASTERskill.md`, Gemini Pro, WSL, Codex, Claude, scripts, references, deployment and rebuild logic |

## Promotion Rules

How to use this chronology:

- **GPT builder file:** use as narrative and governance backbone
- **Paper:** use as chronology source, keep evidence labels visible
- **Repository / skill work:** canonical source files are upstream; meta-governance is governing; deployed copies are downstream realizations
- **Future rebuilds:** do not flatten operator lineage, skill lineage, and implementation lineage into one undifferentiated phase

## Best One-Sentence Version

The project moved from a relational AI writing companion into a governed multi-operator workflow, used deliberate cross-use of AIs to generate and pressure prompts, then evolved into modular skill infrastructure and meta-governed cross-agent implementation through [[HEPHAISTOS|Hephaistos]], WSL, Codex, and Claude.

## Key Ideas

- Brain-heavy early phase (relational, voice, authorship) gives way to governance-heavy middle phase (containment, review discipline) and then skeptical, modular, self-auditing late phase
- Promotion and completion are explicitly separated; governance arbitration is not implied by fluency
- The project's strongest claim: cross-AI use was deliberate triangulation strategy, not platform-hopping
