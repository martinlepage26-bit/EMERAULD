# RECURSO — Recursive Governance Test Archive

## Summary

RECURSO and POST-RECURS are the primary test archives for Martin Lepage's recursive governance methodology, located at `/mnt/d/MASTER PACK/RECURSO/` and `/mnt/d/MASTER PACK/POST-RECURS/`. RECURSO contains the original recursive governance corpus, governance run artifacts, and METAMETADATA layer; POST-RECURS contains stress-test outputs across multiple AI systems (Claude, ChatGPT, DeepSeek). Together they form the empirical substrate for the [[RECURSO Full Integration — Fluency, Interruption, and Theoretical Synthesis]] manuscript and the [[RECURSO — Final Audit and Ethical Review]]. The methodology that produced them is documented in [[MASTERxMASTERxMASTER — Skill Corpus Map]] under `recursive-governance-method`.

## Context

RECURSO is the test bed where the [[AI Society Manuscript — From AI Anxiety to Recursive Governance]] governance claims were empirically validated across multiple AI systems. The RECURSO archive predates the APEX paper line in chronological sequence: the governance runs generated data that fed the manuscripts. The audit described in [[RECURSO — Final Audit and Ethical Review]] covers a 14-layer architecture (Layer 0–13) with two unresolved synchronization issues and a SHADOWMASTER counter-architecture identified as the virtue-ethical failure mode of the system.

See also `/mnt/d/MASTER PACK/APEX_PAPERS_COMMON/` (paper outputs) and [[APEX Papers — Research Archive Map]] for the downstream manuscript line.

## Directory Structure

### RECURSO (`/mnt/d/MASTER PACK/RECURSO/`)

- **`RECURSOTRUE_unpacked/`** — the unpacked recursive corpus; contains:
  - `RECURSO/` — core governance run materials
  - `SCRIPTS/` — execution scripts for governance run orchestration (including `Paper outcomes RESTART TESTS/` with per-agent restart runs)
  - `__pycache__/` — Python build artifacts
  - `governance_drag_drop.cmd` — Windows drag-drop entry point for governance run ingestion
  - `governance_runs/` — output directory for completed governance runs
- **`METAMETADATA/`** — metadata-of-metadata layer containing:
  - `METADATA/` — structured metadata across the corpus
  - `SKILL.md` — governance method skill file embedded in the metadata layer
  - `ai_governance_deliverables_package/` — packaged deliverables from governance runs

### POST-RECURS (`/mnt/d/MASTER PACK/POST-RECURS/`)

- **`Recursox3/`** — three-pass recursive stress-test outputs including:
  - `3FINALFINAL3/` — final triple-pass synthesis
  - `CLAUDE/`, `Chat GPT/`, `DeepSeek Stress-test/` — per-system stress-test runs
  - `FINALE CLAUDE/` — Claude final-pass outputs
  - `Mobius protocol extrait de ChatGPT+Claude/` — Möbius protocol cross-system extracts
  - `MÖBIUS PROTOCOL — CLAUDE-ST OPERATIONAL.txt` — operational Möbius stress-test protocol
  - `THESEUS PASS.txt` — Theseus-by-replacement continuity pass
  - Desktop and Downloads intake folders (2026-03-29 reorganization)
- **`STRESS-TESTS/`** and **`STRESS-TESTS.zip`** — archived stress-test corpus

## Key Concepts in the Archive

- **Recursive loop detection** — identifying where generated artifacts re-enter the analysis as if they were source material
- **SHADOWMASTER** — counter-architecture identified as the virtue-ethical failure mode of the RECURSO system (per [[RECURSO — Final Audit and Ethical Review]])
- **Möbius Protocol** — stress-test design where the model is confronted with its own prior output in a continuity loop
- **Theseus pass** — continuity test via progressive replacement of source components
- **METAMETADATA layer** — governance-on-governance: a second-order analysis of the metadata produced by the first-order runs
