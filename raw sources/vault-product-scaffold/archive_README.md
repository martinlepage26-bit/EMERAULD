# archive/

See also [[Manuscript Pipeline MOC]].
**Purpose:** Completed, retired, or superseded material.

Notes come here when they are:
- Fully synthesized into wiki/ (raw originals after processing)
- No longer active (old project notes, resolved decisions)
- Superseded by a newer version in wiki/

**Rules for the agent:**
- Do not search archive/ by default. Only look here if the user asks for historical material or wiki/ has a gap.
- When archiving, keep the original filename — do not rename.

**Rules for the human:**
- Don't delete. Archive. You may need it later.
- Periodically review: if archived material becomes relevant again, move it back to raw/ for re-synthesis.
