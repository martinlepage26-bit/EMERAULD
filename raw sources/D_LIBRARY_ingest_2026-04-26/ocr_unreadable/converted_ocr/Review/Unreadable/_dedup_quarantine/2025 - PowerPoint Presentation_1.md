Hands-On-Learning: Applying
a Mitigation Strategy

Description
In this practical, code-based lab, you will be given a snippet of vulnerable Python
code representing a simple image classifier. Your task is to implement a data-

centric defense by adding a specific input sanitization function to protect the
model from malformed and invalid inputs.

Learning Objectives
By the end of this activity, learners will be able to:
• Read and understand a simple Python function for

AI model inference.
• Identify the lack of input validation as
a security vulnerability.
• Implement a basic data sanitization function in Python.
• Write defensive code to mitigate threats from invalid inputs.

Assignment Components

Introductory Slide
Title: Code a Defense: Hardening an Image Classifier
Subtitle: Go from vulnerable code to a resilient model by implementing a
critical security control.
Tools to be used:
○ Python programming environment (e.g., Coursera's in-browser lab)
○ Pillow (PIL) library for image handling (will be pre-installed)

Scenario
You are an ML engineer tasked with hardening a prototype for an image
classification model before it gets deployed to production. The core prediction

function was written quickly and does not contain any safety checks. Your task is to
add input sanitization to ensure the function can gracefully handle invalid inputs
without crashing, which will mitigate potential denial-of-service vulnerabilities.
