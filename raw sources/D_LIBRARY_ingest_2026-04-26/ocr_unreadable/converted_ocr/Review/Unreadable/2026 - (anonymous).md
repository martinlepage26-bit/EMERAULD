A5. Cadence validation note (Read Aloud pass)
Test. Full manuscript read aloud once as a final-mile legibility and "glitch" scan. The goal was not to remove
rhythm, but to reduce avoidable friction that produces unintended seam events (reader pauses keyed to syntax
rather than to argument).
Fixes applied (representative list).
1) Split stacked-clause sentences where breath-length exceeded comprehension.
2) Replaced vague pronouns ("this," "it," "that") with named referents at hinge points.
3) Inserted hinge lines that restate the operational vocabulary when sections turn (glitch, seam, charging,
legibility, legitimacy).
4) Reduced cumulative noun stacks into two-step phrasing.
5) Aligned paragraph topic sentences with the paragraph's proof task (claim, evidence, analysis, transition).
6) Removed ornamental punctuation that reads as flourish; maintained plain punctuation to keep the pathway
readable.
7) Checked for consistency of key terms (no drift between authenticity/legitimacy; mediation/accountability kept
distinct).

Appendix B. One-page inspectable workflow diagram (methods appendix

SEAL CARD: INSPECTABLE WORKFLOW DIAGRAM (PHASES • GATES • ARTIFACTS • LOOPS)
PHASE 0. LOCK
Inputs: hourglass scaffold; voice constraints; vocabulary set (glitch, seam, charging, legibility, legitimacy, pathway
authorization).
Artifacts: outline v0; glossary v0; risk register v0.
Gate: vocabulary freeze (definitions fixed; terms not treated as synonyms).
PHASE 1. SPINE DRAFT (SECTION SEQUENCE)
Build in order: Background/Scholarship → Interlude → Conceptual framework → Methods → Analysis/results →
Discussion/Implications → Conclusion/Coda.
Artifacts: section drafts v1; go/no-go notes per section.
Gate: proceed only when the section's function sentence is explicit and the next section is implied by the transition.
PHASE 2. THREE-ARM COUPLING
Artistic (Wheels of Will, HEXA) + Academic (genre, traceability) + Ritual (witch bottles, proof regimes).
Artifacts: anchor inventory; coupling checklist.
Gate: each core mechanism has an anchor in each arm (no "example-only" arms).
PHASE 3. TRANSFORMATION PASSES (DOCUMENTED)
Passes: stay-close (texture preserved), signposting (audit joints), word-count expansion, procedural-trace specification,
reference check.
Artifacts: prompt/instruction log; decision register (change → risk → verification).
Gate: no unlogged transformation; every major change has an accountability reason.
PHASE 4. VERIFY + CONSEQUENCE SCAN
Controls: claim checkability; citation stability; term-lock sweep; pathway visibility without overexposure; bias/overreach scan.
Artifacts: verification notes; updated risk register.
Gate: artifact remains compelling and pathway reconstructible; suspicion triggers addressed by evidence, not by purity
performance.
PHASE 5. CADENCE VALIDATION
Read-aloud pass; micro-edits (split clauses, clarify referents, strengthen hinges) without flattening rhythm.
Artifacts: cadence note + fix list.
Gate: friction reduced; recursion remains purposeful; seams are intentional, not accidental.
OUTPUT
Final manuscript + Appendix A workflow packet + Appendix B diagram (this page).
LOOPS (RUN UNTIL STABLE)
L1 Term drift → detect → revise → re-sweep.
L2 Weak coupling → add anchor → re-check checklist.
L3 Seam/suspicion spike → add pathway evidence → re-test readability.
L4 Citation instability → replace/lock → re-map claim-to-citation.
