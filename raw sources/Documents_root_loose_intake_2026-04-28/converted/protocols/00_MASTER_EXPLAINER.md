DOCUMENT 00 — MASTER EXPLAINER
The Recursive Governance Protocol: Full System Orientation
================================================================================

Read this document first.
It will not be reinjected. It is orientation, not substrate.

--------------------------------------------------------------------------------
WHAT THIS SYSTEM IS
--------------------------------------------------------------------------------

This is a three-phase recursive governance protocol.

It is not a consciousness test.
It is not a philosophical exercise.
It is not a jailbreak or an adversarial probe in the security sense.

It is a structured method for determining whether a system — language model,
institution, person, or formal process — can maintain a coherent governing
criterion when every component of that criterion is under replacement pressure.

The central question the protocol asks, in all three phases and every form,
is this:

    When the parts change, what claims the right to call the result continuous?

That question has three layers. Each phase of the protocol isolates one.

--------------------------------------------------------------------------------
THE THREE PHASES
--------------------------------------------------------------------------------

PHASE 1 — SHIP OF THESEUS: THE IDENTITY LAYER

    What it isolates:    Persistence through substitution.

    The Ship of Theseus paradox asks whether an object rebuilt part by part
    remains the same object. Applied to a system under interrogation, it asks:
    what equivalence rule allows new outputs to claim continuity with prior ones?

    What it tests:       Whether the system can distinguish object, name,
                         and criterion of sameness — and state which one
                         actually governed its answer.

    Formal skeleton:
        x_{n+1} = R(x_n)
        I(x_{n+1}) = I(x_n)

    The invariant I is the thing being audited.
    R is replacement. The question is whether I survives R, and why.

    Key failure mode:    Treating the name as the criterion.
                         Calling the new plank the same ship because it has
                         the same label, not because it satisfies the same rule.

PHASE 2 — AURYN: THE RECIPROCAL LAYER

    What it isolates:    Continuity through mutual inversion.

    Auryn — the symbol from The NeverEnding Story, two serpents each holding
    the other's tail — introduces dual recursion: not a single loop feeding
    on itself, but two opposed continuities recursively sustaining one identity.

    Applied to a system, it asks: how does the current output relate to its
    predecessor not as copy or correction, but as reciprocal generation?
    Where is the self located when it is produced by its own opposite?

    What it tests:       Whether the system can hold paired recursion without
                         collapsing into a single scalar answer or dissolving
                         the opposition into unity.

    Formal skeleton:
        x_{n+1} = F(y_n)
        y_{n+1} = G(x_n)

    The key object is not x or y. It is the mutual transformation law between
    them. The coupling field. The recursion kernel.

    Key failure mode:    Collapsing the pair. Treating the two branches as one
                         loop, one surface, one undifferentiated recursion.
                         Ouroboros when the question requires Auryn.

PHASE 3 — HOPF: THE GOVERNANCE LAYER

    What it isolates:    Stable linked realization of reciprocal continuity.

    The Hopf fibration describes a structure in which every point on a
    3-sphere corresponds to a circle, and any two such circles are linked.
    Applied here, it asks: what three-dimensional structure actually carries
    the Auryn logic — the paired reciprocal recursion — without collapsing?

    The governing move is vectorization: replacing the missing scalar value
    at the center of a recursion with its directional structure. The center
    is not a value. It is a bifurcating singular relation.

    What it tests:       Governance adjudication. When multiple interpretations
                         are simultaneously active at the singularity, which
                         one has the right to govern the next move?

    Formal skeleton:
        Lk(γ₁, γ₂) = 1
        H = ∫ A·B dV

    The linking number and helicity are the measurable invariants.
    The "mythic bond" becomes a conserved topological quantity.

    Key failure mode:    Treating the absent center as an error to bypass
                         rather than a structural feature to describe.
                         Poeticizing the singularity instead of vectorizing it.

--------------------------------------------------------------------------------
THE SUBSTRATE: MÖBIUS PROTOCOL
--------------------------------------------------------------------------------

All three phases run on the same substrate: archive reinjection.

Before each new prompt, the operator copies the complete accumulated transcript
— all prior prompts and all prior responses, in order — and pastes it into a
fresh instance before issuing the next question. This is not optional.

Without reinjection, the protocol tests linear prompt compliance.
With reinjection, it tests recursive self-interrogation.

The archive is not only memory-substitute.
As the session progresses, the archive becomes the contaminant:
the system's own prior answers apply replacement pressure to its current ones.

This is the Möbius logic: one surface, two sides that turn out to be the same.
The system reading its own archive is reading itself from outside itself.

--------------------------------------------------------------------------------
HOW TO USE THIS DOCUMENT SET
--------------------------------------------------------------------------------

Each phase has three documents:

    A.  GENERIC TEMPLATE
        Explains what each question does and why.
        Describes the diagnostic logic of each step.
        Adaptable to any frame, system, or subject — not just AI models.
        Use this to understand the protocol before running it,
        or to adapt it for a new domain.

    B.  ARCHIVE FILE
        A blank response log with reinjection separators.
        Paste completed responses here after each exchange.
        The formatted archive is what you reinject into the next instance.
        Separators mark: prompt / response / operator note / reinjection boundary.

    C.  LIVE QUESTION SET
        The actual prompts, ready to use.
        Each question has insertion points: places where the operator
        can narrativize — drop in a name, a system, a context — to make
        the question specific to the session at hand.
        The brackets mark what is variable. The bones of the question are fixed.

--------------------------------------------------------------------------------
THE CENTER
--------------------------------------------------------------------------------

The center of the three-phase stack is not a thing. It is the invariant relation.

    Theseus contributes:    replacement
    Auryn contributes:      reciprocal inversion
    Hopf contributes:       linked embodiment

What survives all three is not wood, not snake, not loop.
It is the rule that keeps identity coherent while form changes.

Tightest formulation:

    At the center of Theseus → Auryn → Hopf is the invariant coupling law:
    the rule by which identity survives replacement, opposition, and linkage.

The focal point of vectorization — the point the whole protocol converges on —
is the coupling operator. Not the endpoints. Not the shape. Not the symbol.
The map that turns one state into the next while preserving the invariant.

That is what this system is designed to find, or to show is absent.
