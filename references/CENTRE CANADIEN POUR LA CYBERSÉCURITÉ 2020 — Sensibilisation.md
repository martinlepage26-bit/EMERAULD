# Sensibilisation

## Citation
CENTRE CANADIEN POUR LA CYBERSÉCURITÉ (2020). Considérations liées à la sécurité dans le cadre de l’utilisation de logiciels libres. Série « Sensibilisation », juillet. En ligne: https://www.cyber.gc.ca/fr/orientation/considerations-liees-la-securite-dans-le-cadre-de-lutilisation-de-logiciels-libres.

## Annotation
This Canadian Centre for Cyber Security awareness publication addresses the security considerations involved in using open-source software, offering guidance on managing risks such as vulnerabilities, provenance, and maintenance. As a government security-guidance document, it belongs to the cybersecurity-governance literature. For this corpus it grounds practical governance concerns around software supply chains and open-source risk.
