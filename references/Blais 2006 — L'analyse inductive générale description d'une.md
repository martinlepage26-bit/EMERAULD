# L'analyse inductive générale : description d'une

## Citation
Blais, M. et Martineau, S. (2006). L'analyse inductive générale : description d'une

## Annotation
Blais and Martineau's article describes the general inductive approach to qualitative data analysis, following Thomas (2006), for both novice and experienced researchers. They set out its aims: condensing raw data into summary form, linking research objectives to categories emerging from the data, and developing a framework or model grounded in that analysis. Published in Recherches qualitatives, it is a widely used francophone methods reference. For method-focused work in this corpus, it grounds inductive qualitative analysis.
