# Automating Inequality: How High-Tech Tools Profile, Police, and Punish the Poor

## Citation
Eubanks, Virginia. Automating Inequality: How High-Tech Tools Profile, Police, and Punish the Poor. New York: St. Martin's Press, 2018.

## Annotation
Virginia Eubanks's Automating Inequality documents in granular detail how automated decision systems in U.S. public services — welfare eligibility, homeless services, child-welfare risk scoring — systematically disadvantage poor and marginalized people while presenting outcomes as neutral. Eubanks argues that these tools function as a “digital poorhouse,” encoding moral judgments about the poor. The book is a foundational text in critical data and AI studies. For this corpus it grounds the claim that algorithmic harm is a failure of political accountability, not merely engineering.
