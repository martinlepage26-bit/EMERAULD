# C-26, Code des professions

## Citation
RLRQ (2023). C-26, Code des professions. En ligne: https://www.legisquebec.gouv.qc.ca/fr/document/lc/C-26.

## Annotation
The Code des professions (RLRQ, c. C-26) is Québec's foundational statute governing the province's professional-regulation system and its professional orders (ordres professionnels), setting the framework for licensure, ethics, and discipline. As a binding legal instrument, it is a primary governance source. For this corpus it is relevant to how AI intersects with regulated professions and professional deontology in Québec.
