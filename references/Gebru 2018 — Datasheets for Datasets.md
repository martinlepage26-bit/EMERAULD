# Datasheets for Datasets

## Citation
Gebru, T., Morgenstern, J., Vecchione, B., Vaughan, J., et al. (2018). Datasheets for Datasets. arXiv preprint https://arxiv.org/abs/1803.09010

## Annotation
Gebru and colleagues' “Datasheets for Datasets” (the arXiv preprint) proposes standardized documentation for machine-learning datasets, modeled on datasheets in electronics, to record provenance, composition, collection, intended uses, and limitations. The proposal pushes governance upstream to the dataset layer, before model development. It became a foundational reference in responsible-AI and data-documentation practice. For this corpus it grounds the argument that governance failures often begin with weak source hygiene.
