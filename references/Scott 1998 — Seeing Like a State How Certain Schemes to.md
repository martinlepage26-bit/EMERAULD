# Seeing Like a State: How Certain Schemes to Improve the Human Condition Have Failed

## Citation
Scott, James C. Seeing Like a State: How Certain Schemes to Improve the Human Condition Have Failed. New Haven: Yale University Press, 1998.

## Annotation
James C. Scott's Seeing Like a State is a landmark analysis of how states impose “legibility” on complex societies through simplification, standardization, and “high-modernist” schemes — cadastral maps, scientific forestry, planned cities — that ignore local, practical knowledge (mētis) and often fail catastrophically. For this corpus it is highly relevant: a canonical account of how top-down quantification and legibility projects go wrong, directly applicable to data systems, metrics, and AI-driven governance.
