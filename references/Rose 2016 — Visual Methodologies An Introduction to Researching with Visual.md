# Visual Methodologies: An Introduction to Researching with Visual Materials

## Citation
Rose, Gillian. 2016. Visual Methodologies: An Introduction to Researching with Visual Materials. 4th ed. London: Sage.

## Annotation
Gillian Rose's Visual Methodologies is a leading textbook for researching with visual materials, systematically surveying approaches — from content analysis and semiotics to discourse analysis and audience studies — across the “sites” of production, image, and audiencing. Widely used, it is a standard methods reference. For method-focused work in this corpus, it grounds the rigorous analysis of images and visual culture.
