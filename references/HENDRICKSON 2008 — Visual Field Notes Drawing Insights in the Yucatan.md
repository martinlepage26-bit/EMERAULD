# Visual Field Notes: Drawing Insights in the Yucatan

## Citation
HENDRICKSON, C. (2008). Visual Field Notes: Drawing Insights in the Yucatan. Visual Anthropology Review, 24(2), 117-132. https://doi.org/10.1111/j.1548-7458.2008.00009.x

## Annotation
Carol Hendrickson's “Visual Field Notes” reflects on drawing as part of ethnographic fieldwork in the Yucatán, arguing that making marks on a page engages the anthropologist simultaneously in thinking, seeing, and doing, and that the indexical qualities of drawing generate distinctive insight. Published in Visual Anthropology Review, it is a key reference for visual and arts-based fieldwork methods. For method-focused work in this corpus, it grounds drawing as ethnographic practice.
